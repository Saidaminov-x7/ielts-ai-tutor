# IELTS AI Tutor

Персональный Telegram-репетитор IELTS Academic с русским интерфейсом и SQLite. Уровень A1 → IELTS Academic 7.5 за 26 недель — амбициозная цель, не гарантированный результат. Оценки в приложении учебные; они не являются официальным IELTS Band Score.

## Что реализовано

- Telegram-бот aiogram 3 с webhook-доставкой, пробуждаемой Telegram, и доступом только по `OWNER_TELEGRAM_ID`.
- Постоянное хранилище на SQLAlchemy 2 и миграциях Alembic: программа курса, личный словарь, SRS, ошибки, учебная активность, мини-тесты, настройки, напоминания и AI-расходы.
- Уроки на 8 блоков. День считается завершённым после отметки всех блоков, а не после открытия урока.
- Повторение слов с интервалами 1, 3, 7, 14 и 30 дней, поиском и владельческим словарём.
- Объективная проверка локальным Python без платного API; история результатов, журнал ошибок, анализ слабых тем, streak и отчёты.
- Еженедельные тестовые сессии с таймером и сохранением ответов. Это учебная проверка, не полный пробный IELTS.
- Writing Examiner на OpenAI API: валидация ответа, предел длины, ограничение запросов/месяца и резервирование бюджета.
- Настройки времени напоминаний и тихого режима. После перезапуска настройки перечитываются из БД.
- Railway serverless sleep для webhook-службы: без исходящих запросов Railway усыпляет контейнер; входящий Telegram webhook его будит. Ежедневный cron запускает отдельный кратковременный trigger, который вызывает защищённый endpoint и отправляет слова текущего дня.
- Идемпотентный импорт XLSX без изменений оригинала и с JSON-отчётом.

## Текущие ограничения

Рабочая папка изначально была пустой. Подготовленный курс `IELTS_7_5_250_istoriy_26_nedel_182_dnya_PRO.xlsx` не найден, `TELEGRAM_BOT_TOKEN`, `OWNER_TELEGRAM_ID` и `OPENAI_API_KEY` не настроены. Поэтому исходные 182 дня, 1750 слов и готовые материалы Reading/Listening не были импортированы или придуманы. Без токена нельзя проверить реальный Telegram polling; без OpenAI key — реальный Writing API. Ежедневные встроенные вопросы — ограниченный стартовый набор общей грамматики, а не замена полной программе. Адаптивная логика и отчёты используют сохранённую активность, но пока не строят полный персональный недельный срез. Напоминания пока не охватывают SRS и незавершённые блоки. Повторяющиеся Writing ошибки не агрегируются.

Импортёр распознаёт заголовки `day/day_number/день`, `topic/theme/тема`, `grammar/грамматика`, `reading/чтение`, `listening/аудирование`, `writing/письмо`, `objectives/цели/задания`, а для словаря — `english/word/слово`, `translation/перевод/русский`, `transcription/транскрипция`, `example/пример`. Реальную книгу нужно проверить и, если заголовки отличаются, добавить подтверждённое соответствие по её фактической структуре.

## Локальный запуск

Требуется Python 3.12+. В PowerShell из каталога проекта:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e ".[dev]"
Copy-Item .env.example .env
```

Заполните `.env`: `TELEGRAM_BOT_TOKEN`, `OWNER_TELEGRAM_ID` (числовой Telegram ID). `OPENAI_API_KEY` нужен только для Writing. Установите `DATABASE_URL=sqlite:///./data/ielts.db` локально. Затем:

```powershell
python -m app.main
```

При первом запуске Alembic применяет версии схемы к БД. Бот отвечает только пользователю с заданным ID. Не помещайте ключи в сообщения, исходники или Git.

Чтобы проверить подключение, отдельно задайте явный API-ключ и используйте обычный запуск; бот не делает запросов к OpenAI при старте. Первая проверка Writing будет платной и ограничена конфигурацией бюджета.

## Импорт курса

Поместите оригинальный XLSX в каталог проекта или укажите абсолютный путь:

```powershell
python -m scripts.import_course "C:\полный\путь\IELTS_7_5_250_istoriy_26_nedel_182_dnya_PRO.xlsx"
```

Результат импорта и предупреждения будут сохранены в `data/import-report.json`. Исходная книга открывается только для чтения. Повторный запуск обновляет учебные дни по номеру, а словарь не дублирует по паре английское слово + перевод.

## Настройка и стоимость AI

- `MONTHLY_AI_BUDGET_USD`: программный лимит (по умолчанию $2).
- `AI_INPUT_PRICE_PER_MILLION`, `AI_OUTPUT_PRICE_PER_MILLION`: цена модели из актуального прайсинга OpenAI; их необходимо сверить до включения запросов.
- `MAX_DAILY_AI_REQUESTS`: число запросов в сутки.
- `MAX_WRITING_CHARS`: предел текста.
- `OPENAI_MODEL`: модель должна реально поддерживаться API-ключом.

Модель намеренно не проверялась и не переключалась автоматически: ключ отсутствует. Стоимость рассчитывается из заданных тарифов и сообщённых API токенов; задержка биллинга провайдера и параллельные экземпляры могут привести к расхождению. Один процесс рекомендован.

## Railway

1. Создайте Railway webhook service из приватного GitHub-репозитория.
2. Добавьте persistent volume и смонтируйте его в `/data`.
3. Задайте переменные из `.env.example`; `WEBHOOK_BASE_URL` должен быть HTTPS-доменом службы.
4. Включите Serverless для webhook service. Он засыпает, когда не посылает исходящие пакеты; входящий запрос пробуждает его. Первое сообщение может прийти с задержкой холодного старта.
5. Создайте отдельный cron service из того же репозитория с командой `python -m app.daily_trigger`, расписание `0 19 * * *` (00:00 Asia/Tashkent), `DAILY_JOB_URL=https://<domain>/internal/daily` и таким же `DAILY_JOB_SECRET`.
6. Установите `DATABASE_URL=sqlite:////data/ielts.db` только на webhook service. Том прикреплён только к этому сервису; cron обращается к сохранённой БД через защищённый HTTPS endpoint.
7. Проверьте Telegram webhook и ежедневный trigger в логах deployment. Не считайте статус сборки подтверждением реальной доставки.

Dockerfile запускает Python как непривилегированный пользователь. `/health` предназначен для платформенной диагностики, но не настраивайте частый внешний heartbeat — он будет будить спящий контейнер. SQLite не рассчитан на несколько реплик; webhook service запускается одним экземпляром.

## Данные и приватность

Учебные ответы и тексты хранятся в SQLite. При запросе проверки Writing отправляется только выбранный пользователем текст, тип задачи и системная инструкция в OpenAI API; история сообщений и Telegram-идентификатор не отправляются. Токен Telegram используется только локально для Telegram Bot API. Журналы не выводят значение ключей, а сканер секретов печатает только имя файла и строку.
